# embodied-ai-learning

零基础跨行具身智能（Embodied AI）的学习与产出仓库。

## 目标

- **硬指标**：2027-01-31 前入职具身智能行业
- **路径**：自媒体内容运营 → 数据运营/数据工程 → 场景交付 → 创业准备
- **节奏**：工作日每天 2-3 小时，周末 5 小时，每天提交到 GitHub

## 目录结构

```
embodied-ai-learning/
├── 01-python/          # Python 基础（第 1-4 周）
├── 02-data/            # 数据采集与处理（第 2-3 月）
├── 03-industry/        # 产业图谱、企业清单、行业观察
├── 04-content/         # 自媒体稿件与素材
└── logs/               # 每日学习日志
```

## 每日日志

每天的学习记录放在 `logs/` 下，文件名格式 `YYYY-MM-DD.md`。
